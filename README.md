# Домашняя работа 9

## Условие задачи

Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа, условие заполнения фигуры и задаваемые параметры фигуры в таблице (остальные можно взять константные).

Фигура — четырёхугольник. Условие заполнения — да. Задаваемые параметры — углы α и β. Стороны фигуры являются константами.

## 1. Алгоритм и блок-схемы

### Алгоритм:

1. Начало.
2. Объявить переменные:
- **s** — символ, которым будет нарисована фигура.
- **a** — значение первого угла α.
- **b** — значение второго угла β.

3. Ввести с клавиатуры символ и значения углов α и β.

4. Вывести на экран четырёхугольник.

5. Заполнить внутреннюю часть фигуры введённым символом.

6. Вывести значения углов α и β.

7. Конец.

## 2. Реализация программы

```c
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    char s;
    int a;
    int b;

    puts("Введите символ:");
    scanf_s(" %c", &s, 1);

    puts("Введите угол alpha:");
    scanf_s("%d", &a);

    puts("Введите угол beta:");
    scanf_s("%d", &b);

    printf("\n");

    printf("      %c%c%c%c%c%c%c%c%c%c%c%c%c\n", s,s,s,s,s,s,s,s,s,s,s,s,s);
    printf("       %c%c%c%c%c%c%c%c%c%c%c%c\n", s,s,s,s,s,s,s,s,s,s,s,s);
    printf("        %c%c%c%c%c%c%c%c%c%c%c\n", s,s,s,s,s,s,s,s,s,s,s);
    printf("         %c%c%c%c%c%c%c%c%c%c\n", s,s,s,s,s,s,s,s,s,s);
    printf("          %c%c%c%c%c%c%c%c%c\n", s,s,s,s,s,s,s,s,s);
    printf("           %c%c%c%c%c%c%c%c\n", s,s,s,s,s,s,s,s);
    printf("            %c%c%c%c%c%c%c\n", s,s,s,s,s,s,s);

    printf("\nУгол alpha: %d\n", a);
    printf("Угол beta: %d\n", b);

    return 0;
}
```
